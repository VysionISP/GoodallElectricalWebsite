The Work

What we get called for.

If the gear is plugged in and the data still isn't moving, the answer is almost always between the wall and the cabinet. We trace it properly.

Wi-Fi dead spots

Bad placement, wrong AP density, or interference. We heat-map the venue, identify where coverage actually drops out, and place APs to fix it.

EFTPOS / POS keeps disconnecting

Usually a flaky cable run, an overloaded switch port, or shared comms with too much chatter. We trace it properly and fix the cause, not the symptom.

Comms room that nobody can read

Spaghetti rack, no labels, no documentation. We cut the rack back, terminate cleanly, label every port, and leave you with a diagram.

Adding network points

New work area, new POS terminal, new TV with smart streaming — we run Cat6/Cat6A and balance the network so the new gear doesn't degrade the old.

CCTV that nobody can actually use

Bad camera placement, low-spec NVR, no remote access. We design coverage that works and set up secure remote viewing for the manager.

New site or fitout

Greenfield comms — we design the rack layout, plan cable routes, and install + commission ready for the fit-out crew to follow.

FAQ

Newry questions, answered straight.

Do you do communications & networks work in Newry?

Yes — Newry is well within our normal run from Sale. Call 03 4130 5012 or send through the job details and we'll come back with a proper scope and quote.

Do you do residential as well as commercial?

Mostly commercial — venues, motels, small offices, retail fitouts. We do some residential structured cabling for new builds and major renos.

Can you configure the switches and APs, or just run the cable?

Both. We pull the cable, terminate the ports, install the switches and APs, configure them, and document what we've done.

How much does a network install cost?

Heavily dependent on cable count and complexity. A handful of new points + a small switch is half a day; a full venue comms refit is multiple days plus commissioning. We quote on site. Service-call rate during business hours is $149 inc GST for the first 30 minutes, then $125 per hour + GST; after-hours is $195 per hour + GST.

Do you handle data + electrical at the same time?

Yes — we're licensed electricians, so we coordinate the power runs with the data cabling in a single pass.
