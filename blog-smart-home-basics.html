Smart home automation: where to actually start.

28 July 2026 · 4 min read · Goodall Electrical Team

Most homeowners come to us wanting "the whole smart home thing" and then get stuck deciding where to begin. The honest answer: start with whatever you'll actually use every day, and build the wiring so the rest can be added later without ripping open walls a second time.

1. Lighting first — it's the highest-use system

Smart lighting is the automation people interact with most, and it's the cheapest to retrofit properly if the wiring is done right the first time. Scene control (one button for "movie night" or "cooking") gets used daily. Voice control is a nice extra, not the main event.

2. Climate — set it and mostly forget it

Zoned, scheduled heating and cooling pays for itself in running costs and doesn't need daily interaction once it's set up. This is a good second step because it rarely conflicts with what you did for lighting.

3. Access control — worth it if you're renovating anyway

Smart locks, garage control and video doorbells are easiest to fit during a renovation when walls are already open. Retrofitting later is possible but usually means more cabling work for the same result.

The wiring decision that actually matters

Whatever you start with, the thing to get right early is a proper low-voltage backbone — data points and control wiring run to a central panel, rather than everything relying on Wi-Fi mesh devices. It costs more upfront and saves you from a house full of battery-powered gadgets that all need separate apps.

  • Decide what you'll actually use daily — not what looks impressive
  • Run cabling to a central point even if you're only automating lighting now
  • Pick one control ecosystem rather than mixing three
  • Have an electrician — not just an app — commission the system
